# RemoveDupeDownloads
 Scans selected folder for files ending with " (#)" and moves all or selected items to a folder named "Deleted"

## Requirements

- Python 3.10 or newer
- PySide6 6.11.3 (installed from `requirements.txt`), which provides wheels for
  Windows 10/11 (x64 and ARM64), macOS 13 or newer, Linux x86-64 with glibc 2.34 or newer
  (for example Ubuntu 22.04 and later), and Linux ARM64 with glibc 2.39 or newer

## Run

```
pip install -r requirements.txt
python main.py
```
